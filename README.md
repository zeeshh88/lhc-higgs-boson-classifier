# LHC Higgs Boson Classifier & Signal Isolation

This repository contains machine learning models for processing high-energy spectral physics datasets. 

## ⚙️ Project Overview:
* **Framework:** Deployed a Gradient Boosting Classifier pipeline.
* **Objective:** Automatic background noise filtration and invariant mass track isolation.
* **Application:** Validated via high-resolution ROC-AUC curve analysis for the National Centre for Physics (NCP) ILMI-2026 symposium presentation.
